Get started

Up and running in a few steps.

Use the included patcher to build your Reforged shader pack from the required shader files. The original SEUS and Photon ZIPs are supplied by you, not redistributed here.

Download Reforged ↗
Before you start: Install OptiFine HD U G5+ or Iris, then obtain the required shader files from their respective sources.
01

Download Reforged

Get the latest release from the GitHub Releases page and extract the ZIP.

02

Get the required shader files

Download SEUS PTGI HRR 2.1, Bliss v2.1.2, and Photon v1.3b from their respective sources.

03

Run Apply Patch

For the simplest method, double-click Apply Patch.bat. You can also drag the original SEUS and Photon ZIP files onto it.

04

Let the patcher do the work

The patcher searches for the required files, verifies them, and generates your Reforged shader pack. If asked to install it automatically, press Enter to accept the default.

05

Enable the shader in Minecraft

Place the generated ZIP in your shaderpacks folder if it was not installed automatically, then select it in your shader settings.
